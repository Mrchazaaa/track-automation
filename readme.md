## Setup

1. Copy `config.env.example` to `config.env` and set your LALAL.AI API key.
2. Run, for example: `./get_track.sh "https://www.youtube.com/watch?v=5JUjFN9AuFU" "GodGaveMeFeetForDancing"`.

`config.env` is intentionally ignored and must not be committed.
